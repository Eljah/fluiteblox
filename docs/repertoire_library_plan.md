# Recorder Repertoire Library Plan

This backlog is an import plan for a soprano recorder library. It separates repertoire value from legal/import readiness:

- `yes_with_own_arrangement`: the melody/composition appears safe enough to use only if we create our own recorder arrangement and do not copy a modern edition.
- `maybe_after_source_check`: keep in the roadmap, but do not bundle until a reliable score source and rights status are confirmed.
- `no`: keep as curriculum metadata only; do not ship score data without a license.

Primary evidence sources used:

- Russian blockflute programs and repertoire lists, including the School 75 blockflute program and Rakhmaninov school blockflute program.
- Tatarstan educational program PDFs and methodology pages mentioning Tatar folk/Tatar composer repertoire.
- Public-domain score repositories and public-domain recorder libraries: IMSLP, Mutopia, and public-domain classroom recorder libraries.

Suggested import waves:

1. Level 1 folk/beginner set: Hot Cross Buns, Mary Had a Little Lamb, Twinkle Twinkle, Frere Jacques, Как под горкой, Во поле береза стояла, Про кота, Перепелочка.
2. Russian/Tatar cultural starter set: Туган тел, Әпипә, Кәрия-Зәкәрия, Райхан, Алмагачлары, Бию. Use only own melody-line arrangements.
3. Public-domain classical set: Ode to Joy, Tchaikovsky Children's Album excerpts, Handel/Bach/Purcell/Mozart/Haydn items after exact work identification.
4. Metadata-only curriculum set: Kabalevsky, Shostakovich, Poulenc, Vitlin, Pushechnikov, Mayzel, Krein, Muzaffarov, and protected arrangements by Faizi/Zhiganov.

Before bundling any piece, create a source note containing:

- source URL or bibliographic reference,
- composition copyright status,
- arrangement/editor copyright status,
- whether the app arrangement was created in-house,
- MusicXML/MIDI generation date.
